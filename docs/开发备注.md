# 开发备注

## 编译前置

Windows 建议使用：

```powershell
rustup default stable-x86_64-pc-windows-msvc
cargo build
```

`hidapi` 已启用 `windows-native` feature，直接通过 Windows `hid.dll` 访问 HID，避免额外打包 hidapi C 动态库。

## 当前代码注意点

1. `src/protocols/a7_compatible.rs` 是从公开 A7 项目的 JS 逻辑移植来的。
2. `src/protocols/g3.rs` 是占位，不会假装已经支持 G3。
3. 如果 G3 与 A7-compatible 协议相同，应将 `a7_compatible.rs` 重命名为 `mchose_common_v1.rs`。
4. `tray-icon / muda` 菜单支持动态修改文本；动态增删设备菜单项可以放到下一阶段。
5. 目前托盘菜单只显示“当前设备”，多个设备时通过左键切换当前设备。

## 后续建议

- 先验证协议，不要先优化 UI。
- 如果 `cargo run -- --scan --debug` 读不到 G3，优先抓网页日志。
- 如果要做开机自启，建议后续加入 `auto-launch` 或直接写 Windows Registry。
