# MCHOSE Battery Tray 方案与待办

## 1. 项目目标

做一个 **无窗口、无 WebView、只存在于 Windows 系统托盘** 的小工具，用于显示 MCHOSE / 迈从鼠标的电量和充电状态。

目标体验：

```text
托盘图标：显示当前鼠标电量档位
鼠标悬停：G3：83% · 未充电
右键菜单：普通系统托盘菜单，展示当前设备、电量、状态、刷新、重扫、退出
左键点击：多个鼠标之间切换；只有一个鼠标时刷新
```

## 2. 为什么不用 Tauri / WebView

这个需求不需要设置页，也不需要前端界面。Tauri 最大的优势是 WebView UI，但这里反而会增加常驻内存。

推荐技术栈：

```text
Rust
  ├─ hidapi：读取 HID Feature Report
  ├─ tray-icon：创建系统托盘图标和右键菜单
  ├─ winit：提供 Windows 事件循环
  └─ image：加载 PNG 托盘图标
```

预估常驻内存：

```text
纯 Rust 托盘：约 8–25 MB
Tauri 无窗口托盘：约 15–40 MB
Tauri + WebView：约 60–150 MB+
```

## 3. 当前已知 A7 协议

来自公开项目：`https://github.com/LiyaandNina/MaiCong-A7-Check-Battery`

已知信息：

```text
VID = 21075 = 0x5253
PID = 4129  = 0x1021
Report ID = 0x11
查询命令原始 dataPart：
  06 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
发送前每个字节 XOR 0xFF
实际 send_feature_report：
  11 f9 ff ff ff ff ff ff ff ff ff ff ff ff ff ff ff ff ff ff ff
```

返回解析：

```text
response 每个字节 XOR 0xFF 得到 raw
payload = raw[2..]
payload[9]  = 电量百分比
payload[10] = 充电状态
  0 = 未充电
  1 = 充电中
```

## 4. G3 支持策略

当前用户实际设备：

```text
A7
G3
```

A7 先按已知协议正式支持。

G3 不直接写死支持，需要验证：

```text
1. 插入 G3
2. 运行 cargo run -- --scan --debug
3. 看 G3 是否能被 A7-compatible 协议读出合法电量
4. 如果能读出，说明 G3 复用同一电量协议
5. 如果失败，抓 MCHOSE 网页 WebHID 日志，补 src/protocols/g3.rs
```

注意：公开 A7 项目 README 中出现过 `isG3Mouse` 相关逻辑，因此 G3 可能存在单独分支。不要在未验证前宣传“G3 已正式支持”。

## 5. 软件架构

```text
src/main.rs
  程序入口，解析 --scan --debug，初始化托盘事件循环

src/app_state.rs
  设备状态、电量状态、充电状态、当前设备切换逻辑

src/hid_scan.rs
  枚举 HID 设备，对候选设备尝试所有协议

src/tray.rs
  托盘图标、tooltip、右键菜单、菜单事件 ID

src/icons.rs
  根据电量和充电状态选择图标

src/protocols/mod.rs
  协议适配器 trait 与协议列表

src/protocols/a7_compatible.rs
  已知 A7 / A7-compatible Feature Report 协议

src/protocols/g3.rs
  G3 协议占位，后续根据日志补充
```

## 6. 托盘右键菜单设计

第一版使用普通系统菜单，不做自定义窗口：

```text
MCHOSE Battery
────────────
当前设备：G3
电量：83%
状态：未充电
协议：A7-compatible
────────────
刷新
重新扫描设备
退出
```

后续增强：如果 `tray-icon / muda` 菜单动态更新足够稳定，再添加设备列表：

```text
✓ G3 · 83% · 未充电
  A7 · 61% · 充电中
```

## 7. 图标策略

Windows 托盘图标很小，不建议直接显示 `83%` 文字，容易糊。

推荐：

```text
托盘图标：电池档位
tooltip / 菜单：精确百分比
```

电量档位：

```text
unknown
0
20
40
60
80
100
charging-20
charging-40
charging-60
charging-80
charging-100
```

第一版内置 PNG；SVG 源文件放在 `assets/tray/svg/`，后续可以替换成更精致图标。

